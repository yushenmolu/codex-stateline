## Download

Download **Codex-Stateline.exe** below and double-click it on **Windows 10/11 x64**. That is the only file needed. `SHA256SUMS.txt` is optional verification, not a dependency.

- No installer, Node.js installation, npm commands, source checkout, manual extraction or administrator access.
- Bundled official Node.js runtime and app resources; automatic verified user-local caching.
- Existing native window, tray, single-instance reveal and owned-server shutdown behavior.
- No bundled account, credentials, conversation history or machine-specific configuration.

This is a companion for an existing Codex installation. Generation benchmarks still use your existing Codex CLI and login/relay settings; previews use system Microsoft Edge. The executable uses the Windows PowerShell/.NET/WPF system components.

Quit the old version from its tray menu before replacing the EXE. The executable is currently unsigned, so Windows SmartScreen may show an unknown-publisher warning. Verify this repository and the optional checksum; do not disable system protection.
